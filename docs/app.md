# app

`apps/app` に、web と同じ仕事を載せる。正本は api の一冊だけ。端末に二冊目は持たない。オフラインの帳簿は完成の外。

app は起動設定で api の URL を持つ。ブラウザ用の web は経由しない。接続先を入れる画面は足さない。

## やること

- 起動設定で api の URL を持ち、記録・直す・消す・戻すと暦月の一覧（#31）
- 枠の追加と改名、分類、枠別振り返り（#32）

## やらないこと

端末内の帳簿、オフライン同期、接続先を入れる画面、web と違う分類の規則、名簿。

## これで足りる

app から、web と同じ一冊に今週の実費を残せる。月末に枠つきで収支を見られる。枠の名前を app から足せる。
