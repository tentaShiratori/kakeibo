# 枠

枠は家計簿の中の実体である。名前は一冊の中で一つ。階層も向きも持たない。入出金は枠を 0 または 1 個参照する。理由は [ADR-0011](./adr/0011-optional-category.md)、[ADR-0013](./adr/0013-one-category-per-entry.md)、[ADR-0016](./adr/0016-waku-name-list.md)。

利用者が枠の一覧で名前を足す・改める。付いている入出金がある枠は消さない。改名は枠の名前だけ変える。記録中に名前は足さない。一覧は家計簿と同じ画面の、記録とは別の区画に置く。ルートは増やさない。

振り返りは、暦月の収入合計・支出合計・収支に加え、枠ごとと枠なしのそれらを見ることである。足し算は api の query が行う。枠なしも一行出す。月の数字と枠別の足し算は一致する。理由は [ADR-0015](./adr/0015-review-includes-waku.md)。

正本の段では合計を web が足していた。枠別を足すこの段で、月の合計も枠別も api に移す。

## やること

- api に枠の実体（追加・改名、使用中は消さない）（#27）
- 入出金に枠を 0 または 1（#28）
- 暦月の振り返り query（月の収支、枠別、枠なし）（#29）
- web に枠の区画と分類と枠別振り返り（#30）

## やらないこと

階層、向き、枠の必須化、記録フォームからの名前作成、使用中の枠の削除、app。

## これで足りる

名前を付けた枠を一件に 0 または 1 個付けられる。その月の収支と、枠別と枠なしの合計が見られる。枠別を足すと月の数字と合う。
