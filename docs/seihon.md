# 正本を api にする

家計簿の正本を、空の api の一冊に切り替える。ブラウザの一冊は移さず捨てる。理由は [ADR-0014](./adr/0014-api-source-of-truth.md)。

web は起動設定で api の URL を知る。ブラウザは web 経由で届く。api は今のまま認証なし。戻すは、同じ画面にいる間だけ。暦月の合計は、この段では今どおり web が足す。

## やること

- web が起動設定で api の URL を持ち、サーバ経由で届ける（#25）
- 一覧・記録・直す・消すの正本を api にする。localStorage の帳簿をやめる（#26）

## やらないこと

ブラウザ一冊の移行、枠、振り返り query、認証、app、接続先を入れる画面。

## これで足りる

空の api に今週の実費を残せて、同じ web で翌週も見られる。ブラウザの保存を空にしても残る。
