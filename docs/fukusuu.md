# 複数人

実装しない。issue は作らない。

家計はプロダクトに一つである（[ADR-0009](./adr/0009-single-household.md)）。立てた api が一つの入口であり、認証は足さない。名簿は持たない（[ADR-0007](./adr/0007-no-household-members.md)）。合言葉も、接続先を入れる画面も足さない。

人に渡すのは web の URL である。その配置の web は同じ api を指す。app を使う人には、起動設定用の api の URL を渡す。

名簿を開くと「誰の支出か」に落ちる。合言葉を足すと、持っている人を数え始める。完成に必要なのは、同じ一冊に複数人が書けることであって、人を数えることではない。
